# Daikibo Factory Downtime Analysis

An interactive data analytics solution built in **Tableau** to monitor industrial telemetry, track machine downtime, and evaluate operational performance across multiple manufacturing facilities and device categories.

---

## 📊 Project Overview
Manufacturing facilities generate massive streams of telemetry data that can be difficult to interpret at scale. This project leverages Tableau to transform raw factory data into an actionable, interactive dashboard. Operations and management teams can easily pinpoint bottleneck machines, compare performance metrics across factories, and investigate the root causes of unexpected downtime.

## 🚀 Key Features & Technical Highlights
* **Interactive Telemetry Tracking:** Visualizes real-time and historical machine metrics to monitor overall equipment effectiveness (OEE).
* **Custom Calculated Fields:** Developed advanced Tableau calculated fields to accurately isolate, measure, and categorize machine downtime events.
* **Cross-Filtering & Drill-Downs:** Configured intuitive cross-filters allowing users to seamlessly slice performance data by specific factories, production lines, and device types.
* **Performance Metric Evaluation:** Establishes clear KPIs for downtime frequency, duration, and impact on production workflows.

## 🛠️ Tech Stack
* **Data Visualization:** Tableau Desktop / Tableau Public
* **Data Analytics:** Custom Calculations, Aggregations, Performance Metrics
* **Domain:** Industrial IoT (IIoT), Telemetry Data Analysis, Manufacturing Operations
